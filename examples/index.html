Achieve 3.0 examples

These working examples show how Achieve handles browser resources, HTTP methods, servlets, conditional requests, and media.

Start the ordinary example server with node start.js, open http://localhost:8989/, and explore the links below. Basic servlet examples use bare .jss, the protected CommonJS shorthand. The advanced XML example uses .jss.mjs for a protected ES module servlet.

Examples on the ordinary server

  • Confirm that static files and a servlet work
  • Make a GET request to a servlet
  • Compare HEAD metadata with a bodyless response
  • Send POST data to a servlet
  • Play a small MP4 through Achieve's media handling

Focused examples

Conditional requests and representation ETags uses node examples/conditional/server.js and prints its browser URL.

Application directory selection uses node examples/application_directory/server.js and demonstrates setAppPath() with an ordinary nested directory.

Engineering verification and failure fixtures remain under tests/.
