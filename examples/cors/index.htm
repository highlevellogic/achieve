CORS policy test

This example tests a browser request between two different origins.

Run the Achieve server being tested on port 8989. Serve this test page from a second server on port 8990.

Open this page at http://localhost:8990. The page will make a request to http://localhost:8989. Because the ports are different, the browser treats them as different origins and applies CORS policy.

Expected before CORS is enabled: start the 8989 server with start.js. The browser should block the request because the Achieve server does not return an Access-Control-Allow-Origin header permitting http://localhost:8990. See dev tools console for CORS error message.

Then restart the 8989 server with cors8989.js: node cors8989. This startup file contains the allowOrigin configuration for http://localhost:8990.

For additional CORS features, see the documentation and Quick Start guide.
