Startup: an Achieve application

This example demonstrates a normal startup file and a separate application directory containing public resources and protected servlets.

From the repository directory, start Node from this example's directory:

cd examples/basics/startup
node startup.mjs

Then open http://localhost:8989/. If the examples catalog is already using port 8989, stop it before starting this focused application.

The first line of startup.mjs loads Achieve using modern ESM syntax. Achieve also supports CommonJS startup files.

setAppPath("./application") selects this application/ directory. The relative path starts from the directory where Node is started, so run this example from examples/basics/startup. listen() then starts the server.

setAppPath() is optional, but recommended: it lets an application live wherever its developer chooses and makes the relationship between URL paths and application directories explicit. Strictly, only loading Achieve and calling listen() are required.

Intermediate examples introduce more Achieve configuration options.

Expected result: this page loads, and the hello servlet returns a response from server-side code.
