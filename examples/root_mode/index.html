One application directory

This directory is one complete Achieve application. Its accounting/ and ROOT/ directories are ordinary URL directories within the same containment boundary.

From the repository directory, start the focused demonstration server:

node examples/root_mode/server.js

Then open http://localhost:8990/. Try /accounting/ and /ROOT/ as directories in that application.

The demonstration server keeps running for browser exploration; press Ctrl+C to stop it.

Separately, run node tests/root_mode/verify.js for automated default and configured application-directory checks.
