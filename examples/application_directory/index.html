One application directory

Achieve uses the server project's root directory as the default application directory. Use setAppPath() to specify a different application directory, as this focused server does.

The accounting/ directory is an ordinary URL directory inside this application. It does not select another application or change the containment boundary.

From the repository directory, start the focused demonstration server:

node examples/application_directory/server.js

Then open http://localhost:8990/ and try /accounting/.

The demonstration server keeps running for browser exploration; press Ctrl+C to stop it.

Separately, run node tests/application_directory/verify.js for automated default and configured application-directory checks.
