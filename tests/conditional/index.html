Conditional requests and representation ETags

From the repository directory, start this focused demo with node tests/conditional/server.js, then open http://localhost:8991/. The server enables caching and compression.

An ETag identifies the version and representation Achieve sent. Status 200 means Achieve is sending the requested representation. Status 304 means the client already has the current representation, so Achieve does not send it again. Status 412 means a condition attached to the request was not satisfied.

The Node verifier covers identity, gzip, and deflate explicitly because browsers control Accept-Encoding and may transparently decompress responses.
