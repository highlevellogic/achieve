Achieve 3.0 development tests

This application directory contains focused, mostly manual regression tests for the development server.

The preferred protected servlet suffix is .jss. Legacy extensionless .js servlets remain compatibility fixtures, while explicit .js requests remain static.

Browser test applications

  • Basic confirmation and compression
  • GET servlet handling
  • HEAD handling
  • POST servlet handling
  • Caching and ETag handling
  • Conditional requests and representation ETags
  • Directory redirects
  • Media and byte ranges
  • Servlet helper loading

ROOT/application mode setup and fixtures explains how to run the separate focused ROOT-mode application space. Its live ROOT links do not run under this normal simple-mode server.

The jss/ tree contains targeted routing, reload, precedence, error, and source-protection fixtures; several are intentionally invalid and are exercised with their documented request paths.

See README_TESTS.txt in this directory for test organization and expected use.
