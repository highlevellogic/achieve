ROOT/application mode setup

This directory is a complete Achieve application space, not an application running beneath the normal tests/ server.

From the repository directory, start the focused ROOT-mode demonstration server:

node tests/root_mode/server.js

Then open http://localhost:8990/. Its ROOT/ application owns /, and the sibling accounting/ application owns /accounting.

The links on the live ROOT page are not active through the normal simple-mode development server. The demonstration server keeps running for browser exploration; press Ctrl+C to stop it.

Separately, run node tests/root_mode/verify.js for automated configuration and routing checks. The verifier starts and stops its own servers.
