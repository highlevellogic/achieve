ROOT application

This page is ROOT/index.html, served at / while useRoot(true) is active.

  • /accounting/ — the named sibling accounting application.
  • /accounting/collision.txt — expected: accounting collision. The sibling application wins over ROOT/accounting/collision.txt.
  • /accounting/missing.txt — expected: 404. The selected accounting application does not fall back to the matching ROOT file.
  • /servlets/hello — ROOT .jss servlet.
  • /servlets/legacy — ROOT legacy extensionless .js servlet.

useRoot(false) instead serves appPath directly. A missing or non-directory ROOT with useRoot(true) is a startup configuration failure, not an HTTP 404; the focused verifier checks those cases.
