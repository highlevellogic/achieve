Achieve — Server web Node.js yang ramah pengembang

Cara lebih sederhana untuk membangun aplikasi web

Achieve adalah server web dan server aplikasi HTTP untuk Node.js. Achieve menyajikan situs web, menangani permintaan HTTP, dan menjalankan program JavaScript di server.

Pengembang dapat membuat situs sederhana hingga aplikasi web canggih menggunakan JavaScript biasa dan modul Node.js.

Achieve dirancang agar pengembangan aplikasi web lebih mudah, tanpa memaksakan framework yang rumit atau memerlukan banyak dependensi.

Mencari alternatif untuk Express?

Express adalah framework populer untuk membangun aplikasi di Node.js, tetapi bukan satu-satunya pendekatan.

Achieve menawarkan cara berbeda untuk menata aplikasi web. Alih-alih membangun aplikasi di seputar rute dan middleware Express, pengembang dapat menggunakan JavaScript Servlets: modul JavaScript biasa yang menangani permintaan HTTP.

Achieve sendiri adalah server web, sehingga tidak perlu menginstal Express atau framework web lain untuk menangani permintaan.

Pengembang tetap memiliki akses langsung ke Node.js dan dapat menggunakan fungsi, modul, serta API JavaScript yang sudah dikenal.

Jika Anda mencari server web Node.js yang ringan, lingkungan pengembangan backend yang lebih sederhana, atau alternatif untuk Express, Achieve layak dicoba.

JavaScript Servlets

JavaScript Servlets adalah salah satu fitur utama Achieve.

Servlet adalah modul JavaScript biasa yang mengekspor fungsi untuk memproses permintaan HTTP. Achieve memetakan URL yang masuk ke servlet yang tepat, memberikan informasi permintaan, dan menangani respons yang dikembalikan.

Sebagai contoh, servlet sederhana dapat terlihat seperti ini:

{{SERVLET_EXAMPLE}}

Ketika browser meminta servlet, Achieve menjalankan fungsinya dan mengembalikan hasilnya ke browser.

Untuk hasil sederhana, tidak perlu menulis kode penanganan respons HTTP seperti biasanya.

Untuk aplikasi yang lebih kompleks, servlet dapat mengakses objek permintaan dan respons Node.js yang mendasarinya serta mengelola respons secara langsung.

Servlet juga dapat menggunakan fungsi JavaScript biasa, modul bawaan Node.js, dan paket npm tambahan.

JavaScript Servlets menyederhanakan penanganan permintaan tanpa membatasi apa yang dapat dibuat pengembang.

Pengembangan tanpa gangguan yang tidak perlu

Achieve mendukung pemuatan ulang otomatis berkas sumber servlet yang diubah dalam mode pengembangan.

Edit servlet, simpan berkasnya, lalu minta kembali. Achieve memuat kode yang diubah tanpa perlu memulai ulang server.

Hal ini memudahkan eksperimen, pengujian perubahan, dan pengembangan aplikasi secara bertahap.

Achieve juga menyediakan laporan kesalahan yang berguna untuk membantu pengembang menemukan masalah dalam kode aplikasi.

Lebih dari sekadar menjalankan servlet

Achieve menggabungkan eksekusi JavaScript Servlets dengan kemampuan server web dan server aplikasi HTTP.

Achieve mendukung sumber daya statis, perutean URL yang dapat dikonfigurasi, HTTP dan HTTPS, HTTP/2, permintaan bersyarat, kompresi, dan fitur HTTP lainnya.

Aplikasi dapat menyajikan HTML, CSS, JavaScript, gambar, dan sumber daya lain sambil menggunakan JavaScript Servlets untuk pemrosesan backend, seperti menangani formulir, memproses data, atau merespons permintaan JSON.

Karena dibangun di atas Node.js, Achieve memungkinkan aplikasi berinteraksi dengan basis data, layanan eksternal, dan perangkat lunak lain melalui ekosistem Node.js yang luas.

Mulai menggunakan Achieve

Achieve tersedia melalui npm, pengelola paket Node.js.

Dokumentasinya mencakup tutorial pemula, informasi konfigurasi, contoh servlet, dan referensi teknis.
