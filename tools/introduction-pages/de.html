Achieve — Ein entwicklerfreundlicher Webserver für Node.js

Ein einfacherer Weg, Webanwendungen zu entwickeln

Achieve ist ein Webserver und HTTP-Anwendungsserver für Node.js. Er liefert Websites aus, verarbeitet HTTP-Anfragen und führt JavaScript-Programme auf dem Server aus.

Mit gewöhnlichem JavaScript und Node.js-Modulen können Entwickler alles von einfachen Websites bis hin zu anspruchsvollen Webanwendungen erstellen.

Achieve soll die Entwicklung von Webanwendungen unkompliziert machen, ohne ein aufwendiges Framework vorzugeben oder eine große Anzahl von Abhängigkeiten vorauszusetzen.

Auf der Suche nach einer Alternative zu Express?

Express ist ein beliebtes Framework für die Entwicklung von Anwendungen mit Node.js, aber es ist nicht der einzige Ansatz.

Achieve bietet eine andere Möglichkeit, Webanwendungen zu organisieren. Statt Anwendungen auf Routen und Middleware von Express aufzubauen, können Entwickler JavaScript Servlets verwenden: gewöhnliche JavaScript-Module, die HTTP-Anfragen verarbeiten.

Achieve ist selbst ein Webserver. Daher muss weder Express noch ein anderes Webframework installiert werden, um Anfragen zu verarbeiten.

Entwickler behalten direkten Zugriff auf Node.js und können vertraute JavaScript-Funktionen, Module und APIs verwenden.

Wer einen schlanken Webserver für Node.js, eine einfachere Umgebung für die Backend-Entwicklung oder eine Alternative zu Express sucht, sollte sich Achieve näher ansehen.

JavaScript Servlets

JavaScript Servlets gehören zu den zentralen Funktionen von Achieve.

Ein Servlet ist ein gewöhnliches JavaScript-Modul, das eine Funktion zur Verarbeitung einer HTTP-Anfrage exportiert. Achieve ordnet die eingehende URL dem passenden Servlet zu, stellt Informationen über die Anfrage bereit und kümmert sich um die zurückgegebene Antwort.

Für einfache Ergebnisse muss der sonst übliche Code zur Behandlung der HTTP-Antwort nicht geschrieben werden.

Bei anspruchsvolleren Anwendungen kann das Servlet auf die zugrunde liegenden Anfrage- und Antwortobjekte von Node.js zugreifen und die Antwort direkt steuern.

Servlets können auch gewöhnliche JavaScript-Funktionen, integrierte Node.js-Module und zusätzliche npm-Pakete verwenden.

JavaScript Servlets vereinfachen die Verarbeitung von Anfragen, ohne die Möglichkeiten bei der Anwendungsentwicklung einzuschränken.

Entwicklung ohne unnötige Unterbrechungen

Im Entwicklungsmodus unterstützt Achieve das automatische Neuladen geänderter Servlet-Quelldateien.

Bearbeiten Sie ein Servlet, speichern Sie die Datei und rufen Sie es erneut auf. Achieve lädt den geänderten Code, ohne dass der Server neu gestartet werden muss.

So lassen sich bequem Dinge ausprobieren, Änderungen testen und Anwendungen schrittweise entwickeln.

Achieve bietet außerdem hilfreiche Fehlermeldungen, mit denen Entwickler Probleme im Anwendungscode erkennen können.

Mehr als nur die Ausführung von Servlets

Achieve verbindet die Ausführung von JavaScript Servlets mit den Fähigkeiten eines Webservers und HTTP-Anwendungsservers.

Er unterstützt statische Ressourcen, konfigurierbares URL-Routing, HTTP und HTTPS, HTTP/2, bedingte Anfragen, Komprimierung und weitere HTTP-Funktionen.

Anwendungen können HTML, CSS, JavaScript, Bilder und andere Ressourcen ausliefern und gleichzeitig JavaScript Servlets für die Backend-Verarbeitung nutzen, etwa für die Verarbeitung von Formularen und Daten oder die Beantwortung von JSON-Anfragen.

Da Achieve auf Node.js basiert, können Anwendungen über dessen umfangreiches Ökosystem auch mit Datenbanken, externen Diensten und anderer Software zusammenarbeiten.
