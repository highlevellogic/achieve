Achieve — 開発者にやさしい Node.js ウェブサーバー

ウェブアプリケーションをもっとシンプルに開発

Achieve は Node.js 向けのウェブサーバー兼 HTTP アプリケーションサーバーです。ウェブサイトの配信、HTTP リクエストの処理、サーバー上での JavaScript プログラムの実行を行います。

通常の JavaScript と Node.js モジュールを使って、シンプルなウェブサイトから高度なウェブアプリケーションまで開発できます。

Achieve は、複雑なフレームワークや大量の依存パッケージを要求せず、ウェブアプリケーションの開発をわかりやすくすることを目指しています。

Express の代替をお探しですか？

Express は Node.js でアプリケーションを開発するための人気のあるフレームワークですが、唯一の方法ではありません。

Achieve はウェブアプリケーションを構成する別の方法を提供します。Express のルートやミドルウェアを中心に構築する代わりに、HTTP リクエストを処理する通常の JavaScript モジュールである JavaScript Servlets を使えます。

Achieve 自体がウェブサーバーなので、リクエストを処理するために Express や別のウェブフレームワークをインストールする必要はありません。

開発者は引き続き Node.js に直接アクセスでき、使い慣れた JavaScript の関数、モジュール、API を利用できます。

軽量な Node.js ウェブサーバー、よりシンプルなバックエンド開発環境、あるいは Express の代替をお探しなら、Achieve をご検討ください。

JavaScript Servlets

JavaScript Servlets は Achieve の中心的な機能の一つです。

サーブレットは、HTTP リクエストを処理する関数をエクスポートする通常の JavaScript モジュールです。Achieve は受信した URL を適切なサーブレットに対応付け、リクエスト情報を渡し、返されたレスポンスを処理します。

例えば、シンプルなサーブレットは次のように記述できます。

{{SERVLET_EXAMPLE}}

ブラウザーがサーブレットにリクエストすると、Achieve は関数を実行し、その結果をブラウザーに返します。

シンプルな結果であれば、通常必要となる HTTP レスポンス処理のコードを書く必要はありません。

より高度なアプリケーションでは、サーブレットから基盤となる Node.js のリクエスト・レスポンスオブジェクトにアクセスし、レスポンスを直接制御できます。

サーブレットでは、通常の JavaScript 関数、Node.js の組み込みモジュール、追加の npm パッケージも使えます。

JavaScript Servlets は、開発できるものを制限せずにリクエスト処理をシンプルにします。

不要な中断のない開発

Achieve は開発モードで、変更されたサーブレットのソースファイルを自動的に再読み込みできます。

サーブレットを編集して保存し、再度リクエストしてください。Achieve はサーバーを再起動せずに変更後のコードを読み込みます。

これにより、試行錯誤や変更のテスト、段階的なアプリケーション開発がしやすくなります。

Achieve は、アプリケーションコードの問題を特定するために役立つエラー情報も提供します。

サーブレットの実行だけではありません

Achieve は JavaScript Servlets の実行機能と、ウェブサーバーおよび HTTP アプリケーションサーバーの機能を組み合わせています。

静的リソース、設定可能な URL ルーティング、HTTP と HTTPS、HTTP/2、条件付きリクエスト、圧縮などの HTTP 機能をサポートします。

アプリケーションは HTML、CSS、JavaScript、画像などのリソースを配信しながら、フォーム処理、データ処理、JSON リクエストへの応答などのバックエンド処理に JavaScript Servlets を使えます。

Achieve は Node.js 上に構築されているため、その豊富なエコシステムを利用して、データベース、外部サービス、その他のソフトウェアとも連携できます。

Achieve を使い始める

Achieve は Node.js のパッケージマネージャーである npm から入手できます。

ドキュメントには、初心者向けチュートリアル、設定情報、サーブレットの例、技術リファレンスが含まれています。

バックエンドプログラミングを学ぶ方にも、ウェブアプリケーションを構築する方にも、既存の Node.js フレームワークの代替を検討する方にも、Achieve は別のアプローチを提供します。シンプルで柔軟な JavaScript プログラミングモデルを備えた、完全なウェブサーバーです。
