Achieve — Przyjazny programistom serwer WWW dla Node.js

Prostszy sposób tworzenia aplikacji internetowych

Achieve to serwer WWW i serwer aplikacji HTTP dla Node.js. Udostępnia witryny, obsługuje żądania HTTP i uruchamia programy JavaScript po stronie serwera.

Programiści mogą tworzyć zarówno proste witryny, jak i zaawansowane aplikacje internetowe, korzystając ze zwykłego JavaScriptu i modułów Node.js.

Achieve zaprojektowano tak, aby upraszczał tworzenie aplikacji internetowych bez narzucania rozbudowanego frameworka i wymagania wielu zależności.

Szukasz alternatywy dla Express?

Express to popularny framework do tworzenia aplikacji w Node.js, ale nie jest jedynym rozwiązaniem.

Achieve oferuje inny sposób organizowania aplikacji internetowych. Zamiast opierać je na trasach i middleware Express, programiści mogą używać JavaScript Servlets: zwykłych modułów JavaScript obsługujących żądania HTTP.

Achieve sam jest serwerem WWW, więc do obsługi żądań nie trzeba instalować Express ani innego frameworka internetowego.

Programiści zachowują bezpośredni dostęp do Node.js i mogą korzystać ze znanych funkcji, modułów oraz interfejsów API JavaScript.

Jeśli szukasz lekkiego serwera WWW dla Node.js, prostszego środowiska programowania backendu lub alternatywy dla Express, warto poznać Achieve.

JavaScript Servlets

JavaScript Servlets to jedna z głównych funkcji Achieve.

Servlet jest zwykłym modułem JavaScript eksportującym funkcję do przetwarzania żądania HTTP. Achieve przyporządkowuje otrzymany URL do właściwego servletu, dostarcza informacje o żądaniu i obsługuje zwróconą odpowiedź.

Prosty servlet może na przykład wyglądać tak:

exports.servlet = function (session) {
    return "Hello World!";
};

Gdy przeglądarka wysyła żądanie do servletu, Achieve wykonuje funkcję i zwraca wynik przeglądarce.

Przy prostych wynikach nie trzeba pisać typowego kodu obsługującego odpowiedź HTTP.

W bardziej zaawansowanych aplikacjach servlet może korzystać bezpośrednio z obiektów żądania i odpowiedzi Node.js oraz samodzielnie zarządzać odpowiedzią.

Servlety mogą też używać zwykłych funkcji JavaScript, wbudowanych modułów Node.js i dodatkowych pakietów npm.

JavaScript Servlets upraszczają obsługę żądań bez ograniczania możliwości tworzonych aplikacji.

Programowanie bez zbędnych przerw

W trybie deweloperskim Achieve automatycznie przeładowuje zmodyfikowane pliki źródłowe servletów.

Edytuj servlet, zapisz plik i ponownie wyślij do niego żądanie. Achieve wczyta zmieniony kod bez konieczności ponownego uruchamiania serwera.

Ułatwia to eksperymentowanie, testowanie zmian i stopniowe rozwijanie aplikacji.

Achieve dostarcza również przydatne komunikaty o błędach, które pomagają programistom znajdować problemy w kodzie aplikacji.

Więcej niż uruchamianie servletów

Achieve łączy wykonywanie JavaScript Servlets z możliwościami serwera WWW i serwera aplikacji HTTP.

Obsługuje zasoby statyczne, konfigurowalne trasowanie URL, HTTP i HTTPS, HTTP/2, żądania warunkowe, kompresję i inne funkcje HTTP.

Aplikacje mogą udostępniać HTML, CSS, JavaScript, obrazy i inne zasoby, a jednocześnie używać JavaScript Servlets do pracy backendu: obsługi formularzy, przetwarzania danych czy odpowiadania na żądania JSON.

Ponieważ Achieve działa na Node.js, aplikacje mogą również współpracować z bazami danych, usługami zewnętrznymi i innym oprogramowaniem, korzystając z rozbudowanego ekosystemu Node.js.
