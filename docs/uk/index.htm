Achieve — Зручний для розробників вебсервер Node.js

Простіший спосіб створювати вебзастосунки

Achieve — це вебсервер і сервер HTTP-застосунків для Node.js. Він надає вебсайти, обробляє HTTP-запити та виконує програми JavaScript на сервері.

Розробники можуть створювати як прості вебсайти, так і складні вебзастосунки, використовуючи звичайний JavaScript і модулі Node.js.

Achieve покликаний спростити розробку вебзастосунків, не нав'язуючи складного фреймворку й не вимагаючи великої кількості залежностей.

Шукаєте альтернативу Express?

Express — популярний фреймворк для створення застосунків на Node.js, але це не єдиний підхід.

Achieve пропонує інший спосіб організації вебзастосунків. Замість побудови застосунків навколо маршрутів і проміжного ПЗ Express розробники можуть використовувати JavaScript Servlets: звичайні модулі JavaScript, які обробляють HTTP-запити.

Achieve сам є вебсервером, тому для обробки запитів не потрібно встановлювати Express чи інший вебфреймворк.

Розробники зберігають прямий доступ до Node.js і можуть використовувати знайомі функції, модулі та API JavaScript.

Якщо ви шукаєте легкий вебсервер Node.js, простіше середовище розробки бекенду або альтернативу Express, варто ознайомитися з Achieve.

JavaScript Servlets

JavaScript Servlets — одна з основних можливостей Achieve.

Сервлет — це звичайний модуль JavaScript, який експортує функцію для обробки HTTP-запиту. Achieve зіставляє вхідну URL-адресу з відповідним сервлетом, надає інформацію про запит і обробляє повернену відповідь.

Наприклад, простий сервлет може виглядати так:

exports.servlet = function (session) {
    return "Hello World!";
};

Коли браузер запитує сервлет, Achieve виконує функцію та повертає результат браузеру.

Для простих результатів не потрібно писати звичайний код обробки HTTP-відповіді.

У складніших застосунках сервлет може звертатися до базових об'єктів запиту й відповіді Node.js та безпосередньо керувати відповіддю.

Сервлети також можуть використовувати звичайні функції JavaScript, вбудовані модулі Node.js і додаткові пакети npm.

JavaScript Servlets спрощують обробку запитів, не обмежуючи можливості розробників.

Розробка без зайвих перерв

У режимі розробки Achieve підтримує автоматичне перезавантаження змінених файлів вихідного коду сервлетів.

Відредагуйте сервлет, збережіть файл і надішліть запит до нього знову. Achieve завантажить змінений код без перезапуску сервера.

Це дає змогу зручно експериментувати, перевіряти зміни й поступово розвивати застосунки.

Achieve також надає корисні повідомлення про помилки, що допомагають розробникам знаходити проблеми в коді застосунку.

Більше, ніж виконання сервлетів

Achieve поєднує виконання JavaScript Servlets із можливостями вебсервера та сервера HTTP-застосунків.

Він підтримує статичні ресурси, налаштовувану маршрутизацію URL, HTTP та HTTPS, HTTP/2, умовні запити, стиснення й інші можливості HTTP.

Застосунки можуть надавати HTML, CSS, JavaScript, зображення та інші ресурси й водночас використовувати JavaScript Servlets для бекенд-обробки: роботи з формами, обробки даних або відповідей на JSON-запити.

Оскільки Achieve побудований на Node.js, застосунки також можуть взаємодіяти з базами даних, зовнішніми сервісами та іншим програмним забезпеченням завдяки великій екосистемі Node.js.
