Achieve — Um servidor web Node.js pensado para desenvolvedores

Uma maneira mais simples de criar aplicações web

Achieve é um servidor web e um servidor de aplicações HTTP para Node.js. Ele disponibiliza sites, processa requisições HTTP e executa programas JavaScript no servidor.

Os desenvolvedores podem criar desde sites simples até aplicações web sofisticadas usando JavaScript comum e módulos do Node.js.

Achieve foi projetado para tornar o desenvolvimento de aplicações web direto, sem impor um framework complexo nem exigir uma grande quantidade de dependências.

Procurando uma alternativa ao Express?

Express é um framework popular para criar aplicações com Node.js, mas não é a única abordagem.

Achieve oferece outra maneira de organizar aplicações web. Em vez de estruturá-las em torno das rotas e dos middlewares do Express, os desenvolvedores podem usar JavaScript Servlets: módulos JavaScript comuns que processam requisições HTTP.

Achieve é, por si só, um servidor web. Portanto, não é necessário instalar Express ou outro framework web para processar requisições.

Os desenvolvedores mantêm acesso direto ao Node.js e podem usar funções, módulos e APIs JavaScript que já conhecem.

Para quem procura um servidor web Node.js leve, um ambiente de desenvolvimento backend mais simples ou uma alternativa ao Express, vale a pena conhecer o Achieve.

JavaScript Servlets

JavaScript Servlets são um dos recursos centrais do Achieve.

Um servlet é um módulo JavaScript comum que exporta uma função para processar uma requisição HTTP. Achieve associa a URL recebida ao servlet adequado, fornece informações sobre a requisição e cuida da resposta retornada.

Por exemplo, um servlet simples pode ser assim:

exports.servlet = function (session) {
    return "Hello World!";
};

Quando um navegador solicita o servlet, Achieve executa a função e devolve o resultado ao navegador.

Para resultados simples, não é necessário escrever o código habitual de tratamento de respostas HTTP.

Em aplicações mais avançadas, o servlet pode acessar os objetos subjacentes de requisição e resposta do Node.js e controlar a resposta diretamente.

Os servlets também podem usar funções JavaScript comuns, módulos integrados do Node.js e pacotes npm adicionais.

JavaScript Servlets simplificam o processamento de requisições sem limitar o que os desenvolvedores podem criar.

Desenvolvimento sem interrupções desnecessárias

Achieve permite recarregar automaticamente os arquivos-fonte de servlets modificados no modo de desenvolvimento.

Edite um servlet, salve o arquivo e faça uma nova requisição a ele. Achieve carrega o código alterado sem precisar reiniciar o servidor.

Isso facilita experimentar, testar alterações e desenvolver aplicações de forma incremental.

Achieve também fornece mensagens de erro úteis para ajudar os desenvolvedores a identificar problemas no código da aplicação.

Mais do que executar servlets

Achieve combina a execução de JavaScript Servlets com os recursos de um servidor web e de um servidor de aplicações HTTP.

Ele oferece suporte a recursos estáticos, roteamento de URL configurável, HTTP e HTTPS, HTTP/2, requisições condicionais, compressão e outros recursos HTTP.

As aplicações podem disponibilizar HTML, CSS, JavaScript, imagens e outros recursos enquanto usam JavaScript Servlets no processamento backend, como tratar formulários, processar dados ou responder a requisições JSON.

Como Achieve é baseado em Node.js, as aplicações também podem interagir com bancos de dados, serviços externos e outros softwares por meio do amplo ecossistema Node.js.
