Achieve — Webový server pro Node.js vstřícný k vývojářům

Jednodušší cesta k tvorbě webových aplikací

Achieve je webový server a server HTTP aplikací pro Node.js. Poskytuje webové stránky, zpracovává HTTP požadavky a spouští programy v JavaScriptu na serveru.

Vývojáři mohou vytvářet jednoduché weby i propracované webové aplikace pomocí běžného JavaScriptu a modulů Node.js.

Achieve je navržen tak, aby usnadňoval vývoj webových aplikací, aniž by vnucoval složitý framework nebo vyžadoval velké množství závislostí.

Hledáte alternativu k Express?

Express je oblíbený framework pro tvorbu aplikací na Node.js, ale není to jediný přístup.

Achieve nabízí jiný způsob uspořádání webových aplikací. Místo stavby aplikace kolem tras a middlewaru Express mohou vývojáři používat JavaScript Servlets: běžné moduly JavaScriptu, které zpracovávají HTTP požadavky.

Achieve je sám webovým serverem, takže pro zpracování požadavků není nutné instalovat Express ani jiný webový framework.

Vývojáři si zachovávají přímý přístup k Node.js a mohou používat známé funkce, moduly a API JavaScriptu.

Pokud hledáte nenáročný webový server pro Node.js, jednodušší prostředí pro vývoj backendu nebo alternativu k Express, stojí za to Achieve vyzkoumat.

JavaScript Servlets

JavaScript Servlets patří mezi hlavní funkce Achieve.

Servlet je běžný modul JavaScriptu, který exportuje funkci pro zpracování HTTP požadavku. Achieve přiřadí příchozí URL příslušnému servletu, poskytne informace o požadavku a zpracuje vrácenou odpověď.

Jednoduchý servlet může vypadat například takto:

exports.servlet = function (session) {
    return "Hello World!";
};

Když prohlížeč odešle požadavek na servlet, Achieve spustí funkci a vrátí výsledek prohlížeči.

Pro jednoduché výsledky není nutné psát obvyklý kód pro obsluhu HTTP odpovědi.

V pokročilejších aplikacích může servlet přistupovat k podkladovým objektům požadavku a odpovědi Node.js a řídit odpověď přímo.

Servlety mohou používat i běžné funkce JavaScriptu, vestavěné moduly Node.js a další balíčky npm.

JavaScript Servlets zjednodušují zpracování požadavků, aniž by omezovaly možnosti vývojářů.

Vývoj bez zbytečného přerušování

Ve vývojovém režimu Achieve podporuje automatické opětovné načítání upravených zdrojových souborů servletů.

Upravte servlet, uložte soubor a znovu jej vyžádejte. Achieve načte změněný kód bez nutnosti restartovat server.

To usnadňuje experimentování, testování změn a postupný vývoj aplikací.

Achieve poskytuje také užitečná chybová hlášení, která vývojářům pomáhají odhalit problémy v kódu aplikace.

Více než jen spouštění servletů

Achieve kombinuje spouštění JavaScript Servlets s možnostmi webového serveru a serveru HTTP aplikací.

Podporuje statické zdroje, konfigurovatelné směrování URL, HTTP a HTTPS, HTTP/2, podmíněné požadavky, kompresi a další funkce HTTP.

Aplikace mohou poskytovat HTML, CSS, JavaScript, obrázky a další zdroje a současně využívat JavaScript Servlets pro backendové zpracování, například obsluhu formulářů, zpracování dat nebo odpovědi na JSON požadavky.

Protože je Achieve postaven na Node.js, mohou aplikace prostřednictvím rozsáhlého ekosystému Node.js komunikovat i s databázemi, externími službami a dalším softwarem.
