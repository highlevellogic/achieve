Achieve — डेव्हलपरस्नेही Node.js वेब सर्व्हर

वेब ॲप्लिकेशन तयार करण्याचा सोपा मार्ग

Achieve हा Node.js साठी वेब सर्व्हर आणि HTTP ॲप्लिकेशन सर्व्हर आहे. तो वेबसाइट उपलब्ध करून देतो, HTTP विनंत्या हाताळतो आणि सर्व्हरवर JavaScript प्रोग्राम चालवतो.

साधे JavaScript आणि Node.js मॉड्यूल वापरून डेव्हलपर साध्या वेबसाइटपासून प्रगत वेब ॲप्लिकेशनपर्यंत सर्व काही तयार करू शकतात.

गुंतागुंतीचा फ्रेमवर्क लादल्याशिवाय किंवा मोठ्या प्रमाणात अवलंबित्वे आवश्यक न करता वेब ॲप्लिकेशनचा विकास सोपा व्हावा, यासाठी Achieve तयार केला आहे.

Express ला पर्याय शोधत आहात?

Node.js वर ॲप्लिकेशन तयार करण्यासाठी Express हा लोकप्रिय फ्रेमवर्क आहे; पण तो एकमेव मार्ग नाही.

Achieve वेब ॲप्लिकेशनची रचना करण्यासाठी वेगळा मार्ग देतो. Express चे रूट आणि मिडलवेअर यांभोवती ॲप्लिकेशन उभारण्याऐवजी डेव्हलपर JavaScript Servlets वापरू शकतात: HTTP विनंत्या हाताळणारे साधे JavaScript मॉड्यूल.

Achieve स्वतःच वेब सर्व्हर असल्यामुळे विनंत्या हाताळण्यासाठी Express किंवा दुसरा वेब फ्रेमवर्क स्थापित करणे आवश्यक नाही.

डेव्हलपरना Node.js चा थेट वापर करता येतो आणि परिचित JavaScript फंक्शन, मॉड्यूल व API वापरता येतात.

हलका Node.js वेब सर्व्हर, सोपे बॅकएंड विकास वातावरण किंवा Express ला पर्याय हवा असेल, तर Achieve पाहण्यासारखा आहे.

JavaScript Servlets

JavaScript Servlets हे Achieve चे एक प्रमुख वैशिष्ट्य आहे.

सर्व्हलेट म्हणजे HTTP विनंतीवर प्रक्रिया करणारे फंक्शन एक्सपोर्ट करणारे साधे JavaScript मॉड्यूल. Achieve आलेला URL योग्य सर्व्हलेटशी जोडतो, विनंतीची माहिती देतो आणि परत आलेला प्रतिसाद हाताळतो.

उदाहरणार्थ, साधे सर्व्हलेट असे दिसू शकते:

exports.servlet = function (session) {
    return "Hello World!";
};

ब्राउझरने सर्व्हलेटची विनंती केल्यावर Achieve फंक्शन चालवतो आणि निकाल ब्राउझरला परत पाठवतो.

साध्या निकालांसाठी नेहमीचा HTTP प्रतिसाद हाताळणारा कोड लिहिण्याची गरज नसते.

अधिक प्रगत ॲप्लिकेशनमध्ये सर्व्हलेट, Node.js चे मूळ विनंती व प्रतिसाद ऑब्जेक्ट वापरून प्रतिसादाचे थेट व्यवस्थापन करू शकते.

सर्व्हलेट साधी JavaScript फंक्शन, Node.js मधील अंगभूत मॉड्यूल आणि अतिरिक्त npm पॅकेजही वापरू शकते.

डेव्हलपर काय तयार करू शकतात यावर बंधने न आणता JavaScript Servlets विनंत्या हाताळणे सोपे करतात.

अनावश्यक व्यत्ययांशिवाय विकास

डेव्हलपमेंट मोडमध्ये Achieve बदललेल्या सर्व्हलेट स्रोत फाइल आपोआप पुन्हा लोड करण्यास मदत करतो.

सर्व्हलेट संपादित करा, फाइल जतन करा आणि पुन्हा विनंती करा. सर्व्हर पुन्हा सुरू न करता Achieve बदललेला कोड लोड करतो.

त्यामुळे प्रयोग करणे, बदल तपासणे आणि ॲप्लिकेशन टप्प्याटप्प्याने विकसित करणे सोयीचे होते.

ॲप्लिकेशनच्या कोडमधील समस्या ओळखता याव्यात यासाठी Achieve उपयुक्त त्रुटी संदेशही देतो.

केवळ सर्व्हलेट चालवण्यापेक्षा अधिक

Achieve, JavaScript Servlets चालवण्याबरोबर वेब सर्व्हर आणि HTTP ॲप्लिकेशन सर्व्हरच्या क्षमताही एकत्र आणतो.

तो स्थिर संसाधने, कॉन्फिगर करता येणारे URL रूटिंग, HTTP आणि HTTPS, HTTP/2, सशर्त विनंत्या, कॉम्प्रेशन आणि इतर HTTP सुविधा समर्थित करतो.

ॲप्लिकेशन HTML, CSS, JavaScript, प्रतिमा आणि इतर संसाधने उपलब्ध करू शकतात. त्याच वेळी फॉर्म हाताळणे, डेटावर प्रक्रिया करणे किंवा JSON विनंत्यांना प्रतिसाद देणे अशा बॅकएंड कामांसाठी JavaScript Servlets वापरू शकतात.

Achieve हा Node.js वर आधारित असल्यामुळे ॲप्लिकेशन त्याच्या विस्तृत परिसंस्थेद्वारे डेटाबेस, बाह्य सेवा आणि इतर सॉफ्टवेअरशीही संवाद साधू शकतात.
