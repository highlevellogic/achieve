Achieve — डेवलपर के अनुकूल Node.js वेब सर्वर

वेब एप्लिकेशन बनाने का एक सरल तरीका

Achieve, Node.js के लिए एक वेब सर्वर और HTTP एप्लिकेशन सर्वर है। यह वेबसाइटें उपलब्ध कराता है, HTTP अनुरोधों को संभालता है और सर्वर पर JavaScript प्रोग्राम चलाता है।

डेवलपर साधारण JavaScript और Node.js मॉड्यूल का उपयोग करके सरल वेबसाइटों से लेकर उन्नत वेब एप्लिकेशन तक बना सकते हैं।

Achieve को वेब एप्लिकेशन विकास आसान बनाने के लिए बनाया गया है। यह कोई जटिल फ़्रेमवर्क नहीं थोपता और न ही बड़ी संख्या में निर्भरताओं की माँग करता है।

Express का विकल्प खोज रहे हैं?

Express, Node.js पर एप्लिकेशन बनाने का एक लोकप्रिय फ़्रेमवर्क है, लेकिन यही एकमात्र तरीका नहीं है।

Achieve वेब एप्लिकेशन को व्यवस्थित करने का अलग तरीका देता है। Express के रूट और मिडलवेयर पर आधारित एप्लिकेशन बनाने के बजाय डेवलपर JavaScript Servlets का उपयोग कर सकते हैं: साधारण JavaScript मॉड्यूल जो HTTP अनुरोध संभालते हैं।

Achieve स्वयं एक वेब सर्वर है, इसलिए अनुरोध संभालने के लिए Express या कोई अन्य वेब फ़्रेमवर्क इंस्टॉल करना आवश्यक नहीं है।

डेवलपर को Node.js का सीधा उपयोग मिलता रहता है। वे परिचित JavaScript फ़ंक्शन, मॉड्यूल और API का उपयोग कर सकते हैं।

यदि आप हल्का Node.js वेब सर्वर, सरल बैकएंड विकास वातावरण या Express का विकल्प खोज रहे हैं, तो Achieve को आज़माकर देख सकते हैं।

JavaScript Servlets

JavaScript Servlets, Achieve की मुख्य विशेषताओं में से एक हैं।

सर्वलेट एक साधारण JavaScript मॉड्यूल है जो HTTP अनुरोध संसाधित करने के लिए एक फ़ंक्शन एक्सपोर्ट करता है। Achieve आने वाले URL को सही सर्वलेट से जोड़ता है, अनुरोध की जानकारी देता है और लौटाए गए उत्तर को संभालता है।

उदाहरण के लिए, एक सरल सर्वलेट ऐसा दिख सकता है:

exports.servlet = function (session) {
    return "Hello World!";
};

जब ब्राउज़र सर्वलेट के लिए अनुरोध करता है, तो Achieve फ़ंक्शन चलाकर उसका परिणाम ब्राउज़र को लौटाता है।

सरल परिणामों के लिए सामान्य HTTP उत्तर संभालने वाला कोड लिखने की आवश्यकता नहीं होती।

अधिक उन्नत एप्लिकेशन में सर्वलेट, Node.js के मूल अनुरोध और उत्तर ऑब्जेक्ट का उपयोग करके उत्तर को सीधे नियंत्रित कर सकता है।

सर्वलेट साधारण JavaScript फ़ंक्शन, Node.js के अंतर्निहित मॉड्यूल और अतिरिक्त npm पैकेज भी उपयोग कर सकते हैं।

JavaScript Servlets अनुरोध संभालना सरल बनाते हैं, बिना इस बात को सीमित किए कि डेवलपर क्या बना सकते हैं।

अनावश्यक रुकावटों के बिना विकास

डेवलपमेंट मोड में Achieve, सर्वलेट की बदली गई स्रोत फ़ाइलों को अपने-आप दोबारा लोड करने का समर्थन करता है।

सर्वलेट संपादित करें, फ़ाइल सहेजें और उसके लिए फिर अनुरोध करें। Achieve सर्वर को दोबारा शुरू किए बिना बदला हुआ कोड लोड कर लेता है।

इससे प्रयोग करना, बदलावों को जाँचना और चरणबद्ध तरीके से एप्लिकेशन विकसित करना सुविधाजनक होता है।

Achieve उपयोगी त्रुटि संदेश भी देता है, जिनसे डेवलपर एप्लिकेशन कोड की समस्याएँ पहचान सकते हैं।

सिर्फ़ सर्वलेट चलाने से बढ़कर

Achieve, JavaScript Servlets को चलाने की सुविधा के साथ वेब सर्वर और HTTP एप्लिकेशन सर्वर की क्षमताएँ भी देता है।

यह स्थिर संसाधन, कॉन्फ़िगर करने योग्य URL रूटिंग, HTTP और HTTPS, HTTP/2, सशर्त अनुरोध, कम्प्रेशन और अन्य HTTP सुविधाओं का समर्थन करता है।

एप्लिकेशन HTML, CSS, JavaScript, चित्र और अन्य संसाधन उपलब्ध करा सकते हैं। साथ ही वे फ़ॉर्म संभालने, डेटा संसाधित करने या JSON अनुरोधों का उत्तर देने जैसे बैकएंड कामों के लिए JavaScript Servlets का उपयोग कर सकते हैं।

Achieve, Node.js पर बना है, इसलिए एप्लिकेशन उसके व्यापक इकोसिस्टम की मदद से डेटाबेस, बाहरी सेवाओं और अन्य सॉफ़्टवेयर के साथ भी काम कर सकते हैं।
