Achieve — Un serveur web Node.js convivial pour les développeurs

Une façon plus simple de créer des applications web

Achieve est un serveur web et un serveur d'applications HTTP pour Node.js. Il sert des sites web, traite les requêtes HTTP et exécute des programmes JavaScript côté serveur.

Les développeurs peuvent créer aussi bien des sites simples que des applications web élaborées avec du JavaScript ordinaire et des modules Node.js.

Achieve vise à simplifier le développement d'applications web, sans imposer de framework complexe ni nécessiter un grand nombre de dépendances.

Vous cherchez une alternative à Express ?

Express est un framework populaire pour créer des applications sur Node.js, mais ce n'est pas la seule approche.

Achieve propose une autre façon d'organiser les applications web. Au lieu de les structurer autour des routes et des middlewares d'Express, les développeurs peuvent utiliser des JavaScript Servlets : des modules JavaScript ordinaires qui traitent les requêtes HTTP.

Achieve est lui-même un serveur web : il n'est donc pas nécessaire d'installer Express ou un autre framework web pour traiter les requêtes.

Les développeurs conservent un accès direct à Node.js et peuvent utiliser les fonctions, modules et API JavaScript qu'ils connaissent.

Si vous recherchez un serveur web Node.js léger, un environnement de développement backend plus simple ou une alternative à Express, Achieve mérite votre attention.

JavaScript Servlets

Les JavaScript Servlets constituent l'une des fonctionnalités centrales d'Achieve.

Un servlet est un module JavaScript ordinaire qui exporte une fonction pour traiter une requête HTTP. Achieve associe l'URL entrante au servlet approprié, fournit les informations sur la requête et prend en charge la réponse renvoyée.

Par exemple, un servlet simple peut ressembler à ceci :

exports.servlet = function (session) {
    return "Hello World!";
};

Lorsqu'un navigateur demande le servlet, Achieve exécute la fonction et renvoie le résultat au navigateur.

Pour les résultats simples, il n'est pas nécessaire d'écrire le code habituel de gestion des réponses HTTP.

Pour les applications plus avancées, le servlet peut accéder aux objets de requête et de réponse Node.js sous-jacents et gérer directement la réponse.

Les servlets peuvent aussi utiliser des fonctions JavaScript ordinaires, des modules intégrés à Node.js et des paquets npm supplémentaires.

Les JavaScript Servlets simplifient le traitement des requêtes sans limiter ce que les développeurs peuvent créer.

Développer sans interruptions inutiles

Achieve prend en charge le rechargement automatique des fichiers source de servlet modifiés en mode développement.

Modifiez un servlet, enregistrez le fichier et appelez-le à nouveau. Achieve charge le code modifié sans nécessiter de redémarrage du serveur.

Il devient ainsi pratique d'expérimenter, de tester les modifications et de développer les applications progressivement.

Achieve fournit également des messages d'erreur utiles pour aider les développeurs à repérer les problèmes dans le code de l'application.

Bien plus que l'exécution de servlets

Achieve associe l'exécution des JavaScript Servlets aux capacités d'un serveur web et d'un serveur d'applications HTTP.

Il prend en charge les ressources statiques, le routage d'URL configurable, HTTP et HTTPS, HTTP/2, les requêtes conditionnelles, la compression et d'autres fonctionnalités HTTP.

Les applications peuvent servir du HTML, du CSS, du JavaScript, des images et d'autres ressources tout en utilisant des JavaScript Servlets pour le traitement backend : formulaires, traitement de données ou réponses aux requêtes JSON, par exemple.

Achieve reposant sur Node.js, les applications peuvent aussi interagir avec des bases de données, des services externes et d'autres logiciels grâce au vaste écosystème Node.js.

Premiers pas avec Achieve
