Achieve — En utvecklarvänlig webbserver för Node.js

Ett enklare sätt att bygga webbapplikationer

Achieve är en webbserver och HTTP-applikationsserver för Node.js. Den levererar webbplatser, hanterar HTTP-förfrågningar och kör JavaScript-program på servern.

Utvecklare kan skapa allt från enkla webbplatser till avancerade webbapplikationer med vanlig JavaScript och Node.js-moduler.

Achieve är utformad för att göra utvecklingen av webbapplikationer enkel, utan att påtvinga ett omfattande ramverk eller kräva ett stort antal beroenden.

Letar du efter ett alternativ till Express?

Express är ett populärt ramverk för att bygga applikationer på Node.js, men det är inte det enda tillvägagångssättet.

Achieve erbjuder ett annat sätt att organisera webbapplikationer. I stället för att bygga applikationer kring rutter och middleware i Express kan utvecklare använda JavaScript Servlets: vanliga JavaScript-moduler som hanterar HTTP-förfrågningar.

Achieve är i sig en webbserver, så det finns inget krav på att installera Express eller något annat webbramverk för att hantera förfrågningar.

Utvecklare behåller direkt tillgång till Node.js och kan använda välbekanta JavaScript-funktioner, moduler och API:er.

Om du söker en lättviktig webbserver för Node.js, en enklare miljö för backendutveckling eller ett alternativ till Express är Achieve värt att utforska.

JavaScript Servlets

JavaScript Servlets är en av de centrala funktionerna i Achieve.

En servlet är en vanlig JavaScript-modul som exporterar en funktion för att behandla en HTTP-förfrågan. Achieve kopplar den inkommande URL:en till rätt servlet, tillhandahåller information om förfrågan och hanterar svaret som returneras.

En enkel servlet kan till exempel se ut så här:

exports.servlet = function (session) {
    return "Hello World!";
};

När en webbläsare anropar servleten kör Achieve funktionen och returnerar resultatet till webbläsaren.

För enkla resultat behöver du inte skriva den vanliga koden för att hantera HTTP-svaret.

I mer avancerade applikationer kan servleten komma åt de underliggande objekten för förfrågningar och svar i Node.js och hantera svaret direkt.

Servletar kan också använda vanliga JavaScript-funktioner, inbyggda Node.js-moduler och ytterligare npm-paket.

JavaScript Servlets förenklar hanteringen av förfrågningar utan att begränsa vad utvecklare kan bygga.

Utveckling utan onödiga avbrott

Achieve stöder automatisk omladdning av ändrade källkodsfiler för servletar i utvecklingsläge.

Redigera en servlet, spara filen och anropa den igen. Achieve läser in den ändrade koden utan att servern behöver startas om.

Det gör det smidigt att experimentera, testa ändringar och utveckla applikationer stegvis.

Achieve ger också användbara felmeddelanden som hjälper utvecklare att hitta problem i applikationskoden.

Mer än att bara köra servletar

Achieve kombinerar körning av JavaScript Servlets med funktionerna hos en webbserver och HTTP-applikationsserver.

Den stöder statiska resurser, konfigurerbar URL-routning, HTTP och HTTPS, HTTP/2, villkorliga förfrågningar, komprimering och andra HTTP-funktioner.

Applikationer kan leverera HTML, CSS, JavaScript, bilder och andra resurser samtidigt som de använder JavaScript Servlets för backendbearbetning, till exempel formulärhantering, databearbetning eller svar på JSON-förfrågningar.

Eftersom Achieve bygger på Node.js kan applikationer också samverka med databaser, externa tjänster och annan programvara genom det omfattande Node.js-ekosystemet.

Dokumentationen innehåller handledningar för nybörjare, konfigurationsinformation, servletexempel och tekniskt referensmaterial.

  • Källkod på GitHub
