Achieve v3 Documentation

Achieve is a developer-friendly HTTP server for Node.js. It provides the server behavior so you can concentrate on building your application.

Getting Started

  • Starting the server

    Start achieve with HTTP, HTTPS, or HTTP/2, choose the application location, and run multiple listeners.

  • Static content and audio/video

    Serve static resources and audio/video, work with MIME types, and use default index files.

  • Your first servlet

    Servlets are the entry points to your backend processes, invoked by the server.

  • Handling Input

    Read GET parameters, process POST forms and JSON, and work with streamed request data.

Examples

The Achieve v3 Advanced Examples are complete runnable applications demonstrating MySQL integration, WebSockets and Rooms, Node clustering, XML/SAX streaming, distributed computing, and SOAP services.

This development ZIP bundles the current Achieve v3 code, so it does not require an adjacent development checkout or a published Achieve v3 package.

Download the Achieve v3 Advanced Examples development ZIP.

Extract the ZIP, open a command prompt in the achieve-v3-advanced-examples-dev directory, and install the dependencies: 

npm ci

Start the landing page, MySQL application, and XML/SAX application: 

npm start

Then open http://localhost:8989/. The included README.md gives the specialized startup commands for WebSockets, Cluster, Distributed computing, and SOAP, plus the optional MySQL setup. Stop any other server using ports 8989 or 8990 before starting these examples.
