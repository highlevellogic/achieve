Achieve v3 Documentation

Achieve is a developer-friendly HTTP server for Node.js. It provides the server behavior so you can concentrate on building your application.

Getting Started

  • Starting the server

    Start achieve with HTTP, HTTPS, or HTTP/2, choose the application location, and run multiple listeners.

  • Static content and audio/video

    Serve static resources and audio/video, work with MIME types, and use default index files.

  • Your first servlet

    Servlets are the entry points to your backend processes, invoked by the server.

  • Handling Input

    Read GET parameters, process POST forms and JSON, and work with streamed request data.

Examples

The Achieve 3 Advanced Examples provide a complete, ready-to-run development environment for newcomers, students, teachers, and experienced developers. The six demonstrations cover MySQL, WebSockets and Rooms, Node clustering, XML/SAX streaming, distributed computing, and SOAP services.

The final distribution will install Achieve 3 and its supporting packages from npm. Choose a location and extract the ZIP, open a terminal in the resulting achieve_examples directory, and run: 

npm install
npm start

Then visit http://localhost:8989/. The included INSTALL.htm provides additional instructions, specialized startup commands, and the optional MySQL setup.
